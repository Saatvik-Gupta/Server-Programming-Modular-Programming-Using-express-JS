# Server-Programming-Modular-Programming-Using-express-JS

Topic: Node.js, npm and Express.js

📚 Topics Covered

Node.js: Introduction to server-side JavaScript.

npm: Managing project dependencies and initializing a Node.js project using npm init -y.

Express.js: Creating a server using Express and handling HTTP requests.

Modular Programming: Organizing server-side code into separate modules and files.

Middleware: Using express.json() to parse JSON request bodies and express.urlencoded() to parse URL-encoded form data.

Routing: Implementing static and dynamic routes using app.get().

Environment Variables: Configuring the server port using dotenv and a .env file.

Server Execution: Starting the Express server using app.listen().

💻 Practical Implementation

Created an Express.js server with a health-check endpoint and a dynamic route parameter. Practiced configuring the server port, using middleware, and handling HTTP GET requests.

🛠️ Technologies Used

JavaScript (ES Modules)

Node.js

npm

Express.js

dotenv

🎯 Learning Outcome

Learned the fundamentals of Express.js server development, middleware, routing, environment configuration, and modular server-side programming.
